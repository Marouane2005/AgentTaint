# AgentTaint Security Dashboard

Next.js 15 UI for the Milestone 8 Interactive Security Dashboard.

See the root guide: [docs/dashboard.md](../../docs/dashboard.md).

```bash
# from repo root
make install
make dashboard-install
make api          # :8080
make dashboard    # :3000
```

Tests: `npm test` (Vitest). Lint: `npm run lint`.
